# Design: The editing table
Experience-led personal portfolio using real supplied work as the 3D material. Three.js renders a single dark editing table with framed photographs and film stills. GSAP maps native scroll to an authored camera/object sequence. No generated footage, no paid services, no new runtime dependency.

The visitor meets Harshana, sees creative work expand into an edit, then sees those pieces align into a workflow. Text remains HTML, outside the 3D scene. The final scene points into selected work and the real Axiom website. Scope replaces the opening/story chapters only; full projects, films, experience and contacts remain below.

Retain dark teal/charcoal and orange action colour. Use current self-hosted type with fewer decorative labels. Avoid generic particles, glow, grid backgrounds and repeated entrance effects. Three-dimensional media framing provides depth. Variance 8, motion 8, density 3, following Taste's portfolio guidance. Impeccable: one authored moment, real assets, readable default, bounded checks. The 10K attachment informs forward/reverse story pacing; its generated-video and hosting pipeline is intentionally not used, per owner instruction.

Desktop: text left, scene right. Phone: scene upper half, text in the lower half, then single-column projects. Still mode uses the real images in natural document flow. Four story stops with no mandatory dwell or scroll hijack. Existing anchors preserved. New build delivered as a draft until the 3D experience can be visually reviewed.
